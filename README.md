# Intelligent Book Summarization Platform Using NLP

An AI-powered Book Summary Generator that accepts book text (PDF or TXT upload, or direct paste), applies NLP preprocessing, and leverages Cloud LLMs (Gemini / OpenAI) to produce concise, accurate summaries and key insights.
